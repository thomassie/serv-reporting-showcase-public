# Portfolio Reporting Showcase (public downloads)

Published outputs of a portfolio reporting showcase for an export credit insurer:

- **HTML report** (German): https://thomassie.github.io/serv-reporting-showcase-public/report.html
- **Portfolio-Cockpit for macOS** (Apple Silicon): [latest release](https://github.com/thomassie/serv-reporting-showcase-public/releases/latest)

All data is synthetic. Policies, exporters, country exposures and claims are invented; only the totals are anchored to figures published by SERV. The SERV name and logo are used for presentation only; the project is not affiliated with or endorsed by SERV.

This repository only holds the published files; they are updated from the private source project.
